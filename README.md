### Admin Setup
The default credentials for the admin are configured using environment variables. 
By default, the username is `admin` and the password is `password123`.

To customize the admin credentials, edit your `.env` file:
```
ADMIN_USERNAME=your_custom_username
ADMIN_PASSWORD=your_custom_password
```
